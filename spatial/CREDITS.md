# SPATIAL Lottie assets

All 6 files are original, made in code by Claude for @baqur.ai (make_lotties.py). No third-party assets, no license restrictions.

| File | Size | Frames @60fps | Markers (sync points) |
|---|---|---|---|
| headphones.json | 512x512 | 120 | 60 = drawn |
| drop.json | 512x1024 | 150 | 48 = impact |
| rain.json | 1080x1920 | 120 (seamless loop) | none |
| bird.json | 512x512 | 60 (loop) | 15, 45 = wing_down |
| leaf.json | 512x1024 | 240 | 15, 45, 75 ... = flip |
| burst.json | 1024x1024 | 90 | 0 = impact |

All shapes are ice white #EAF2FF / mist #B7C4D6, so recolouring is a simple colour swap.
Verified to load and play with zero errors in lottie-web 5.12.2.
