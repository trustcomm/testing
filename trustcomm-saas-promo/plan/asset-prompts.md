# Asset prompts — Trustcomm reel

Generate in this order and send them with these file names (a zip works best). Any good image model works (ChatGPT
image, Gemini / Nano Banana, Higgsfield). Download the largest size, PNG if offered.

Rules for every image:
- **No text, letters, numbers, logos, signboards or app screens anywhere.** I draw all UI, the QR code, the shop name
  and the Trustcomm logo in code so they stay sharp and correct.
- Cut-outs go on a **flat pure magenta background #FF00FF**, evenly lit, no shadow on the background, with space around
  the subject. Nothing in these subjects is magenta, so the cut-out stays clean.
- **Phone screens must be flat pure green #00FF00**, no reflections, so I can put the real Trustcomm page inside.
- Same look for all photos: *realistic photography, soft natural daylight, warm, clean, high detail, 50 mm lens*.
- People: everyday South Indian (Karnataka) customers and shop owner, natural clothes, friendly, nothing staged-looking.
